# Available Species

Providentia does not define or control the list of available species. All species are dictated by GHOST (**G**lobally **H**armonised **O**bservations in **S**pace & **T**ime).

For a full description of GHOST and its standards, see the [GHOST reference paper](https://essd.copernicus.org/articles/16/4417/2024/).

## Supported GHOST Versions

Depending on the version specified in `ghost_version` in the [configuration file](Configuration-files.md), the available species may vary. Providentia currently supports the following GHOST versions:

- **[1.2](#ghost-1-2)**
- **[1.3](#ghost-1-3)**
- **[1.3.1](#ghost-1-3-1)**
- **[1.3.2](#ghost-1-3-2)**
- **[1.3.3](#ghost-1-3-3)**
- **[1.4](#ghost-1-4)**
- **[1.5](#ghost-1-5)**
- **[1.5.1](#ghost-1-5-1)**

## Check Available Species

As explained above, the available species depend on the selected GHOST version. For each version, the supported species are listed below on this page. A link to the corresponding `GHOST_standards.py` file used by Providentia is also provided for additional context on the GHOST standards used.
